# 回声 · 桃花小院

像素小院里的书信式 AI 情感树洞：变成一只小猫，走进桃树，把心事写成信。先在 localhost 开发，准备好再上线。原生 Node.js 22+ 服务，面向 2 核 2 GB 服务器的小规模试用；尚未做云端压力测试。

## 已实现

- 每次进入先显示登录/注册或游客选择；关闭窗口也可继续。随后展示项目目的、玩法、隐私与 AI 使用边界公告，实际可见五秒后收起，可暂停阅读或从右下角指南重看。然后显示站主的 100 元初始共享 DeepSeek 额度说明与 API 设置入口，手动关闭后进入小院；首次访问再选择猫咪毛色。公告不会代替聊天数据处理同意。
- 第一次进入树洞先弹出数据与 AI 说明，点击“我了解并同意，开始写信”才展开信纸；关闭、返回或按 Escape 都不会视为同意。同意仅在当前页面内存有效，再次进入无需重复确认，刷新后重新提示。信纸底部保留详情入口；确认本身不会寄出内容。
- 左侧提示纸条在可见状态停留五秒，折成纸飞机沿弧线飞进树洞；底部“纸条”可重放。选猫、打开对话和切到后台时暂停计时或飞行，减少动态效果模式省略折叠与飞行。
- 原创桃花小院场景，直接点击右侧桃树内部的洞口进入书信聊天；小猫可自定义毛色、有六帧跑步跟随动画，支持鼠标/触摸拖动，拖进洞口也能进入。花瓣可关闭，适配小屏幕与减少动态效果。
- 右上角小音符开关背景钢琴，旁边的声音设置可选两首 CC0 钢琴、分别调节音乐和音效。默认曲为 Kistol 的 Forget Me Not 循环版，也可选 jestar 的 A Simple Trifle；开门、信纸、寄信与回信、摸猫、喂食和按钮使用 Kenney CC0 轻音效。摸猫节流，最多三个同时播放的短音效；切后台暂停。小屋、信纸和指南也有声音设置入口。
- 音乐每次载入页面都默认关闭，点击后才下载和解码；默认钢琴约 1.24 MB，另一首约 242 KB，全部音效约 99 KB，由本站提供，浏览器播放，不依赖外部播放器或音乐 API。选曲、音量和音效开关保存在本机，刷新后音乐需重新开启。原作、授权及加工方式见声音记录。
- 左侧木屋可开门进入：小猫趴在地毯上，白手套鼠标可摸头、肚子、爪子和尾巴，分别获得可爱的回应；支持触屏和键盘。心情低时想抱抱，活跃低时打瞌睡，出去跑动增加活跃；小猫永远不会生病或死亡。
- 摸头时两只耳尖错开轻颤，摸尾巴时尾尖围绕固定根部轻摆，仅短时重绘相应部位；动作结束回到原姿势，减少动态效果模式保留表情而省略摆动。
- 北京时间每天一份猫粮，未吃只有半饿，吃后为饱，不累积、不需要购买。浏览器保存养猫状态、最近更新时间和最后喂食日期，刷新和跨天不会重复发放当天已吃的粮。服务端时间用于校准；这是本机轻量养成状态，不跟账号同步。
- 木屋外的留言板支持昵称与密码注册、登录、匿名/署名、收回自己的纸条。每天北京时间 00:00 定时清空留言，重启和访问时也会补清；账号保留。每条 280 字、每人每天 20 条、全站每天 500 条，发言间隔 15 秒。右下角有使用指南，小屏有小屋/留言板快捷入口。
- 固定两阶段 Agent：最多一批三个只读工具，至多两次模型请求，没有 Agent 循环或子 Agent。支持资料卡检索、自助练习、确定性排盘读取。
- 十张带出处的本地知识卡，来自 WHO / NHS 指南、MINT 沟通说明、Kristin Neff 自我关怀与传统文化文献；回信显示实际检索到的来源。没有冒充全文 RAG 或心理诊疗系统。

- 多轮对话，两档各自加载原创回信参考与示例：“先听我说”以温柔倾听为主，不开放练习工具；“一起想办法”可查阅具体方法、共同找一个下一步。六项人工 rubric 用于后续试读，不增加模型打分请求；保留错误、等待、停止和新对话状态。
- 默认使用站主共享 DeepSeek（`deepseek-flash`，关闭思考模式），站主密钥不进入前端。个人 API 支持 DeepSeek、Qwen、Kimi、GLM、豆包、GPT、Gemini 与 Claude 八种官方接口预设，可编辑模型 ID、查看官方控制台、主动测试连接。保存设置不自动调用模型；一封信依然最多两次模型请求。
- 个人密钥只存在当前页面内存，调用时经本站服务器转发，不落文件、日志、账号或浏览器存储；刷新后重新填写。切换收信方会再次确认数据处理，保留已有来信与草稿；个人接口失败不会自动换用共享密钥。小院底部与写信界面均有 API 设置入口。
- 可选本人和对方生日，使用 `lunar-javascript` 排出参考干支。按北京时间、公历、午夜换日；没有出生地真太阳时转换。未知时辰不补造时柱，节气当天的年月柱有不确定性。
- 本站不持久保存树洞对话和生日，浏览器保存猫咪颜色、动效、声音偏好和养猫状态，不加载第三方统计或外部字体。刷新或新对话会丢失当前聊天内容。公开留言与账号保存在独立文件中；发送给所选模型的树洞内容受服务商自身政策约束。
- 每次用户输入 2000 字、最多最近 10 轮上下文、总上下文 20000 字、默认输出上限 800 token。每封信最多消耗两次模型请求；共享服务每天默认全站 100 封信、单连接来源 30 封信，重启不会清空当天次数，失败请求也计数。个人 API 不占共享次数，单连接来源每分钟最多 20 次（含测试），所有来源合计仍最多三条并发、同一来源一条。100 元只表示站主声明的初始共享额度，不是实时余额或程序精确人民币预算。
- 本地运行和可选的非 root 云端系统服务；当前开发流程不会自动部署。

## 本地运行

```powershell
npm.cmd ci
npm.cmd run dev
```

打开 http://127.0.0.1:3180 。后端运行在自己的电脑上，模型仍通过外部 API 调用，默认 DeepSeek。开发模式会在源文件变更后重启服务，刷新浏览器即可查看前端修改。

配置文件优先使用 `ENV_FILE` 指定路径，其次读取项目 `.env`，最后读取用户目录的 `.config/shudong/.env`（Windows：`%USERPROFILE%\.config\shudong\.env`）。复制 `.env.example` 到自己的配置文件后填写密钥，**不要在 `.env.example` 里填写真实密钥**。外部配置修改后需重启服务。所有真实 `.env` 文件均不提交。

访客使用自己的密钥时，在页面的「API 设置」中填写即可，无需修改服务端环境。设置 `SHARED_ACCESS_ENABLED=false` 并重启可关闭站主共享服务，个人 API 仍可用。页面没有充值或收款功能；个人账户余额、价格及模型权限请在服务商官方控制台查看。个人密钥设置只在浏览器安全上下文（HTTPS 或本机 localhost）启用。

每完成一个可用的小功能，提交一个有说明的 commit，再推送到 GitHub。仓库保存源代码和版本历史；README、测试与功能演示可以一起展示项目经历。

```sh
git add .

```

推送会运行 GitHub Actions 的语法和接口测试，不调用付费模型，也不连接云服务器。当前没有自动部署工作流，待决定上线时再添加。

真实 API Key、SSH 私钥、服务器连接信息、个人聊天与原始需求文档均不纳入仓库。

## 可选：准备好后部署到云端

将 `deploy/config.example.json` 的格式复制到用户目录 `.config/shudong/deploy.json`，填入自己的连接信息。部署脚本需要能安装系统服务的管理账号。连接配置保存在仓库之外。

```powershell
python deploy/deploy.py
powershell -ExecutionPolicy Bypass -File deploy/start-preview.ps1
```

部署脚本通过现有专用 SSH 密钥和已核对的主机指纹连接服务器；仅打包明确列出的源文件和运行时依赖，不上传需求文档、测试记录和私人经历。首次部署下载 Node.js 22 官方 Linux 包并核对官方 SHA256。

服务器路径 `/opt/shudong/app`，密钥配置 `/etc/shudong.env`（仅 root 可读），服务 `shudong.service`，以 `shudong` 系统用户运行。计数保存在 `data/quota.json`，内容只有日期、计数及每日更换盐的连接地址散列，不含对话。

隧道启动后访问 http://127.0.0.1:3180 。这会访问远程服务器。隧道和本地开发使用相同本机端口，需要先关闭本地开发再启动隧道。关闭隧道不停止服务器。云端监听 3080，无需开放额外的公网端口。

## 当前边界

养猫与社区测试覆盖喂食幂等、北京时间跨天、心情/活跃归零、抚摸与跑动、密码与会话不明文保存、匿名返回、留言长度与间隔、作者权限、服务重启、零点无人访问时的物理清理，以及桌面/触屏的完整交互。所有自动测试使用临时数据目录，不接触真实账号和模型。

- 当前场景是整体背景与交互热点；木屋和轻量养猫已实现，种植和可行走地图尚未实现。
- 知识库是十张人工整理的短卡，不是心理学或命理完整语料库；没有在线搜索、向量数据库和咨询资质。

- 这是本地试用版，已实现昵称/密码注册，尚未开放公网。没有邮件验证、密码找回、账号云同步或多人并发压力测试；没有 Ollama 或任意自定义接口地址，不是完整合婚/大运预测服务。八种接口通过协议模拟测试，尚未逐家用真实付费账户验证，实际访问还取决于地域、密钥权限、模型生命周期及服务器网络。
- 公网发布前须落实域名、HTTPS、适用的备案、访问控制及滥用防护。当前限流按实际连接来源计算，不信任转发头；日后增加反向代理需设计可信来源策略。
- 调用次数上限不是精确人民币预算；模型费用以所选服务商账单为准。共享余额不足时提示配置个人接口或等待站主充值，不承诺补充日期。远程模型无法保证仅在本地处理数据。
- 本地代码不保存对话，但不等于用户截图、操作系统、代理或模型服务商没有记录；不承诺删除模型服务商已收到的信息。
- WebMCP 草稿工具仅在浏览器支持时注册，只填写草稿，不自动发送。尚未在原生 WebMCP 浏览器验证。
